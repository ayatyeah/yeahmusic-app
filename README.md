# YeahMusic

Липсинг-клипы для TikTok: строки песни печатаются на экране в такт музыке, камера
живёт под бит, а руками можно управлять картинкой — «выстрелить» пальцем, махнуть,
поставить песню на паузу ладонью.

Две версии: программа для компьютера (Python) и веб-версия (PWA) для телефона.

## Что умеет

**Текст и музыка**
- строки печатаются по буквам в момент, когда их поют;
- тайминги расставляются автоматически: локальная модель Whisper или облако OpenAI;
- ключевые слова вылетают крупно по центру и вертикально вдоль краёв кадра;
- «особые моменты» песни идут крупным планом с усиленным битом;
- биты и громкость баса считаются из самой песни (свой анализ на numpy).

**Камера и эффекты**
- окно камеры меняет форму по ходу песни, бьёт в такт, качается, трясётся, улетает от взмаха;
- глитч строк и двоение кадра на сильных ударах, вспышка и «эхо» кадра на дропе;
- эквалайзер по низу экрана, тени-двойники и светящаяся обводка силуэта.

**Руки (MediaPipe)**
- неоновая обводка пальцев;
- «пистолетик»: наводишь, дёргаешь — выстрел со звуком, «ПАУ!», пулевое отверстие,
  а строка, в которую попал, разлетается на буквы;
- взмахи двигают окно камеры, ладонь на камеру ставит песню на паузу, сердечко из двух рук
  рассыпает сердечки.

**ИИ (по желанию, нужен ключ OpenAI)**
- тайминги по облачному распознаванию — точнее и быстрее локального;
- «режиссёр» размечает песню: какие строки крупно, где менять кадр, какое слово вынести.

## Программа для компьютера

Нужны Python 3.12+, Tk и камера.

```bash
python -m venv .venv
.venv/bin/pip install -r requirements.txt
./run.sh            # запуск
./run.sh test       # быстрые тесты (без окон)
```

Положи mp3 рядом с программой — он сам станет треком. Дальше: «📝 Текст» — вставить слова,
«🎙 Автотайминги» — расставить время, «⏱ Тайминги» — поправить руками, «▶ Показать» — показ.

Ключ OpenAI (необязательно) — в файл `.env` рядом с программой:

```
OPENAI_API_KEY=sk-...
```

## Веб-версия (PWA)

Лежит в `docs/`, открывается по адресу GitHub Pages и ставится на телефон как приложение.
Работает целиком в браузере: камера телефона, те же эффекты на canvas, распознавание рук и
силуэта через JS-версию MediaPipe, запись видео прямо в галерею.

Песню и файл разметки (кнопка «📱 Для телефона» в программе) выбираешь на телефоне сами —
на сервер ничего не загружается.

## Из чего сделано

| Файл | Что внутри |
|---|---|
| `main.py` | окно программы, показ, камера, жесты |
| `overlay.py` | прозрачный слой поверх экрана (Qt): текст и эффекты |
| `hands.py` | руки: скелет, «пистолетик», выстрел, сердечко |
| `camfx.py` | зум на лицо, силуэт, формы кадра, пометки строк |
| `beats.py` | биты, темп и громкость баса из песни |
| `autotime.py`, `ai.py` | тайминги: локально и через OpenAI |
| `docs/` | веб-версия (PWA) |
| `test_main.py` | тесты (логика — без окон) |

Песни и тексты в репозиторий не входят.
